How to fetch a file

curl -i {{ request.host_url }}o/brightwater-bank/.well-known/security.txt

Use -i to see the headers too: the Content-Type matters. On Windows, type curl.exe instead of curl, or just open the URL in a browser. No file at /.well-known/? Try /security.txt, then look around the website itself.
